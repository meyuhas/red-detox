## התאריכים - איפה משנים

**מקור אמת אחד:** בלוק `CONFIG` בראש `index.html`.

```js
WEBINAR_DATE: {
  start: '20261004T170000Z',   // וובינר היכרות · יום ראשון 4.10, 20:00 שעון ישראל
  end:   '20261004T180000Z'
}
```

מהערך הזה נגזרים אוטומטית **גם הכיתוב בבאנר וגם הספירה לאחור**. לשנות תאריך וובינר - לשנות רק כאן.

הפורמט הוא UTC. שעון ישראל בקיץ (עד סוף אוקטובר) הוא UTC+3, כלומר `170000Z` = 20:00. בחורף UTC+2, כלומר 20:00 = `180000Z`.

**ששת מועדי הקורס** יושבים במרקאפ בסקשן `לוח המפגשים` (`.sched-row`) ובנוסף ב-`.dates-highlight-bar`, ב-`.dates-strip` שב-`final-cta` וב-`pricing-footer`. אלה סטטיים - טקסט שמופיע ביותר ממקום אחד צריך עדכון בכל המקומות.

מחזור נוכחי: 11.10 · 18.10 · 25.10 · 1.11 · 8.11 · 15.11 - כולם ימי ראשון, 20:00-21:00 בזום.

## מלכודות

- **הווידאו דחוס במכוון.** המקור היה 131MB ב-20Mbps, מעל המגבלה של גיטהאב (100MB לקובץ) ואיטי בטירוף לדף נחיתה. הגרסה כאן 17MB. המקור נשמר ב-`~/GitHub/red-detox/untitled folder/video.mp4` ואינו במעקב.
- **ה-PNG כבדים** - כ-8MB בסך הכל, `hero.png` לבדו 2.1MB. עובד, אבל שווה המרה ל-WebP.
- **`FORMSPREE_ID` הוא עדיין `YOUR_FORM_ID`** - טופס לא מחובר. ההרשמה עוברת דרך קישורי iCount.
- **`ZOOM_LINK` ריק.** ממתין לקישור.
